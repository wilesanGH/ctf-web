    面向:网络安全 / AI 安全 / 隐私保护 / 可信 AI 方向的研究生与青年教师 版本:v1(2026-07)· 由公众号数据管线整理,事实性信息均经官网核实,核实日期随文标注 ⚠️ 免责:截稿、APC、出版模式随时可能调整,投稿前务必以官网为准;本手册不做中介、不承诺录用。

    一、这份手册怎么用¶

    • 时效数据不在这里:当前在征的安全特刊/会议截稿,看每月更新的《在征特刊总表》(关注公众号回复「总表」领取,表中"方向 A"列即安全/可信AI/隐私核心条目)。
    • 这里放的是不常变的判断:渠道怎么选、钱怎么省、坑在哪。

    二、安全方向的四类投稿渠道(按用途选)¶

    渠道 适合 特点
    CCF 安全会议 冲影响力/毕业硬指标 安全四大(S&P / NDSS / USENIX Security / CCS)+ EUROCRYPT 等密码顶会按轮次滚动收稿,错过一轮等下轮;无版面费有注册费
    SCI 期刊特刊(Special Issue) 周期可控、主题对口 客座编辑制,审稿通常快于正刊;认可度看学校政策(部分单位特刊不算或打折,投前先查本单位口径)
    SCI 正刊常规投稿 稳、认可度无争议 周期长(安全类刊常 6–12 个月)

    五、省钱要点(版面费避坑)¶

    1. "订阅/混合刊可免费发"正在缩水:IJIS、ACM 全线已转纯 OA;别按旧印象默认某刊免费,投前查该刊当年的 "How to publish / APC" 页。
    2. 混合刊(Elsevier/Springer/IEEE 大部分、Wiley/T&F 多数)选传统订阅通道即可 0 版面费;投稿系统里别误选 Open Access 选项。
    3. 纯 OA 刊(MDPI 全部、IET 金色 OA、Hindawi 等)必付 APC;导师经费紧张时优先混合刊。
    4. 机构可能有 转换协议/ACM Open 协议覆盖 APC,投前问图书馆。

    六、投前核查清单(5 分钟)¶

    • 中科院分区:以当年官方分区表为准(每年更新);单位认小类还是大类先确认。
    • 预警名单:查最新一版中科院《国际期刊预警名单》;"曾预警后移出"的刊单位口径不一,留证据。
    • 特刊认可度:问学院/研究生院,特刊(Special Issue)是否与正刊同等对待。
    • 会议等级:以 CCF 官方推荐目录为准;非目录会议查 EI/Scopus 检索与主办方,警惕"IEEE/ACM 冠名"的挂牌会。
    • 截稿真实性:以官网为准;特刊常延期,但别赌延期。

    七、安全方向选刊速记(基于本库数据的观察)¶

    • 量大管饱:Elsevier(Computers & Security、COSE 系、Ad Hoc Networks、Computer Networks…)与 Springer(Cybersecurity、IJIS…)的安全特刊供给最稳定。
    • 顶刊难度梯队:TIFS/TDSC(1区,正刊为主)> 2–3 区安全专刊 > 4 区。特刊是 2–3 区刊的高效入口。
    • AI安全/大模型安全是当前特刊热点方向,LLM 安全、联邦学习隐私、对抗鲁棒相关征稿密集——这类交叉主题在 AI 刊和安全刊都能投,按数据/方法侧重选。
    • 具体在征清单 → 回复「总表」看 A 类列。
